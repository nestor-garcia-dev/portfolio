## Selected work

### [Dinaryo](https://github.com/nestor-garcia-dev/dinaryo-case-study)

**Production · Business money management and reconciliation · Private source**

Replaced a small business's daily Excel workflow with a production application for recording activity, reconciling cash, reporting, and tracing changes. The business reports approximately **1,000 records entered per week** and **$800K in monthly reconciliation volume**. Dinaryo records and reconciles money; it does not process payments.

I partnered with the business on requirements and own development, hosting, releases, backups, monitoring, and daily support.

**Built with:** Angular, NestJS, PostgreSQL, AWS, Terraform, and Nx.

[Read the case study](https://github.com/nestor-garcia-dev/dinaryo-case-study) · [Explore the architecture](https://github.com/nestor-garcia-dev/dinaryo-case-study/blob/main/ARCHITECTURE.md)

### [Scalewing](https://github.com/nestor-garcia-dev/scalewing)

**Actively developed · Shared design system · MIT licensed**

A design system for web and React Native applications. Shared tokens define themes and spacing; separate renderers respect each platform's interaction model. Web styles are generated from tokens and shipped with the packages.

The repository includes an interactive local gallery, automated checks, and documented package boundaries. It demonstrates how I structure reusable software across multiple applications.

**Built with:** TypeScript, React, React Native, pnpm workspaces, and Vitest.

[Explore the source and examples](https://github.com/nestor-garcia-dev/scalewing) · [Read the architecture](https://github.com/nestor-garcia-dev/scalewing/blob/main/docs/ARCHITECTURE.md)
